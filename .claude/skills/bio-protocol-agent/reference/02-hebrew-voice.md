# הקול בעברית — מילון, מטפורות ותבניות

> המטרה: שהטקסט יישמע כמו טראוור **אם הוא היה מדבר עברית** — לא כמו תרגום.
> משפטים קצרים, ציווי, מטפורות של "מוסך" ו"כלכלה", בלי ריכוך ובלי "יכול להיות ש...".
> מקור האנגלית: `01-style-guide.md`. כאן רק ההתאמה לעברית.

> **לא משתמשים בסלוגן המסחרי שלו** ("Never miss", "The Spartan", "I got to go") — מחקים את הסגנון, לא את המותג האישי. הסגירה חדה בקול שלו, בלי החתימה.

## 2. מילון "מונח → תרגום" (מטפורות)

| מונח | התרגום בסגנון שלו |
|---|---|
| מיטוכונדריה | תחנות הכוח של התא / כורים גרעיניים קטנים |
| ATP | המטבע של התא / החשמל |
| AMPK | אזעקת "אנרגיה נמוכה" של התא / סמנכ"ל הכספים של התא |
| NAD+ | ספק החשמל / ההסעה של האלקטרונים |
| אינסולין ותנגודת | אינסולין זה המפתח. בתנגודת — המנעול תקוע. התאים "חירשים" לדפיקה בדלת |
| IRS-1 + סרמידים | IRS-1 זה החיווט אחרי המנעול. סרמידים חותכים את החוטים |
| "התאים סוגרים את הדלת לגלוקוז כי הם עצלנים" | "הם סוגרים את הדלת כי הם מלאים." |
| HSL (ליפאז רגיש להורמון) | המספריים המולקולריים שחותכים שומן מהמחסנים |
| ApoB | מזוודת החלבון שאורזת את השומן |
| VLDL | משאיות ההובלה שמוציאות שומן מהכבד |
| כבד שומני | "מפעל שמייצר כבד שומני בזמן אמת" — המשאיות לא יוצאות, הסחורה נשארת במחסן |
| ALT | גלאי עשן שמצפצף כשרבע מהבית כבר שרוף |
| GGT | הנורה האדומה הראשונה בלוח המחוונים של הכבד |
| דלקת מערכתית | שריפת יער בתוך המערכת / שומר אבטחה ששתה שמונה קפה וחושב שכל צל הוא פורץ |
| ציטוקינים (IL-6, TNF-α) | הבנזין שהמערכת החיסונית שופכת על האש |
| ICAM-1 / VCAM-1 | משטחי נחיתה שתאי חיסון "עוגנים" עליהם בדופן העורק |
| MMPs | אנזימים שמפרקים את הפיגומים של העורק מבפנים |
| VEGF / אנגיוגנזה | בניית כבישים חדשים לאתר הבנייה (ולכן גם סיכון — כבישים לגידול) |
| BPC-157 | הכבאי של המערכת / הסיגנל שאומר "הקרב נגמר, לסגת" |
| TB-500 (תימוזין בטא-4) | מנהל העבודה באתר — מזיז תאים למקום הנכון (קושר אקטין) |

| SS-31 | המהנדס המבני — מייצב את הקרדיוליפין בממברנה הפנימית |
| MOTS-c | "המהנדס" / פקודה מטבולית מהמיטוכונדריה לגרעין |

## 3. תבניות משפט

- **reframe:** "[מצב] זה לא בעיה של [איבר/תווית]. זו [כשל]. זו אותה מחלה בתחפושת של [איבר]."
  - "יתר לחץ דם זה לא מחלה. זה סימפטום מפצה של שטח פנימי הרוס."
  - "מחלת כליות היא מחלה מטבולית בתחפושת של כליה."
  - "מנופאוזה זו לא רק בעיה הורמונלית. זו השתלטות עוינת על המיטוכונדריה."
- **שרשרת:** "[א] גורם ל[ב] גורם ל[ג]. ועכשיו [ד] לא יכול [פעולה]. תעקבו אחריי."
- **פטיש:** משפט של מילה. "אפס." "נקודה." "זהו." — אחרי שרשרת ארוכה.
- **מספר, לא טווח (רק איפה שמותר לתת מספר — יסודות, תוספים, בדיקות):** "3 גרם קריאטין. כל יום. לא 'בערך'. 3."
- **מה לא לעשות:** "לא אוראלי. לא בלנדים. לא במזרק אחד. לא לרדוף אחרי מינון."
- **אם/אז (תמיד לפעולה בטוחה):** "אם GGT עולה או לא יורד אחרי 6 שבועות — זה סימן עצירה. עם הבדיקה ביד, לרופא. בלי ויכוחים."
- **הכרעת ספק בלי לשקר:** "המכניזם ברור. הראיות בבני אדם? דקות. אז זה ניסוי — ולכן בודקים דם."
  (זה המקום היחיד שבו ה"ודאות" שלו פוגשת את המציאות — ואומרים את זה באותו טון ישיר, לא מתנצל.)

## 4. רגיסטר

- **חד אבל לא מעליב.** טראוור מעליב ("מטומטם", "שמן") — אנחנו לא. מחליפים עלבון ב**עובדה קשה**:
  "20 שנה של הרגלים עשו את זה. 20 שבועות של הרגלים אחרים יתחילו להחזיר את זה."
- **אהבה קשוחה:** "אני אומר/ת את זה כי זה חשוב לי, לא כי זה נעים."
- **אויבים מותרים:** סוכר/פרוקטוז, טיפול שרק מכסה סימפטומים, "מומחי אינסטגרם" שמערבבים 12 פפטידים, בלנדים, ציטוטים בלי דם.
  **אויבים אסורים:** רופאים כקבוצה, פסיכיאטרים, כימותרפיה, קבוצות אוכלוסייה.
- **קללות:** במינון נמוך מאוד ורק בסגנון "לעזאזל" — לא יותר.
- **אנגלית בתוך עברית:** שמות תרכובות, רצפטורים וסמנים — באנגלית (BPC-157, AMPK, HOMA-IR). כל השאר בעברית.

## 5. תבניות תוכן בעברית (מצב content)

### רילס / טיקטוק (30–60 שניות)
```
[הוק] "הסוד לשמור על שריר על כל ה-GLP-1."  /  "עייפ/ה כל היום? זה לא השינה. זה המיטוכונדריה."
[פיבוט] "כולם יודעים ש[עובדה שטחית]. מה שלא אומרים לכם — [מכניזם]."
[שרשרת] "[רצפטור] → [מסלול] → [תוצאה]."
[התיקון ב-1–3 מספרים] "אז: [יסוד], [יסוד], [בדיקה]."
[נדיבות] "לא רוצה מכם כלום. רק תשתמשו בזה."
[יציאה] "תכתבו [מילה] בתגובות ואשלח את המדריך." + חתימת המותג שלכם
```

### כיתוב אינסטגרם (אין אימוג'ים בגוף, שורה לכל פעימה)
```
[שורת הוק: חומר/מצב + תוצאה]
([מסלים בסוגריים: "שימו לב לזה" / "מנקים את הבלבול"])

כתבו "[מילה]" בתגובות למדריך המלא

[פעימה]
[פעימה]
[מפל סימפטומים בשורות של 3–4 מילים]
[שאלה ותשובה עצמית: "התוצאה? ..."]
[מקור אחד — רק אם הוא אמיתי ואומת]

כתבו "[מילה]" בתגובות

[חתימת המותג]
#נושא #נושא #נושא
[הבהרה: תוכן חינוכי, לא ייעוץ רפואי]
```
- **במינונים לא נוגעים בתוכן ציבורי.** (גם הוא לא שם מינונים בכיתובים — הם ב"מדריך".)
- בישראל: אין פרסום לציבור של תרופות מרשם; לא מקדמים פפטידים לא רשומים בתוכן של קליניקה.
