# ספר מתכונים — סוכן CapCut (computer-use)

הנחיות מדורגות מוכנות להעתקה. מריצים אחת-אחת. כל שלב = הרצה נפרדת של הסוכן,
מוודאים שהצליח, וממשיכים לבא. CapCut צריך להיות **פתוח ובפוקוס**, ושאר החלונות סגורים.

תבנית ההרצה:
```
cd C:\Users\osher\AAA\nanobanana-mcp\agent
agentenv\Scripts\python.exe computer_agent.py --goal "<ההנחיה מהשלב>"
```
עצירת חירום: Ctrl+C. אם שלב נכשל/נתקע — מצמצמים אותו (פחות קליפים, פעולה אחת) ומריצים שוב.

## טיפים מהניסיון
- **הקלדה** עובדת דרך הדבקה (clipboard) — חסינה לעברית. אם בכל זאת מתעוות, ודאי שפריסת המקלדת אנגלית.
- **פוקוס**: ודאי ש-CapCut הוא החלון הפעיל לפני שהספירה לאחור נגמרת.
- **שלב גדול שנתקע** → חלקי אותו לשניים. הסוכן מדייק יותר במשימות קטנות.
- `--max-steps 160` למשימות ארוכות (יותר צעדים = יותר עלות API).
