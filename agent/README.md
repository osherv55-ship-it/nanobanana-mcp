# סוכן Computer-Use ל-CapCut ("עיניים + ידיים")

סוכן שמצלם את המסך, שולח ל-Claude (ראיית מחשב), מקבל פעולה (קליק/הקלדה/גלילה),
מבצע אותה פיזית עם עכבר/מקלדת, ומחזיר צילום מסך חדש — בלולאה עד שהמשימה הושלמה.
מטרה: לערוך ב-CapCut אוטומטית, כולל החלת תבניות.

## ⚠️ ציפיות הוגנות — חובה לקרוא
- **בסיס לעבודה, לא מוצר מוגמר.** ההרצות הראשונות דורשות פיקוח וכיול.
- **רץ מקומית בלבד**, על המחשב עם CapCut, ושולט במסך האמיתי שלך.
- **שביר** — תלוי ברזולוציה, פריסת חלונות, וממשק (עברית מאתגרת לראייה).
- **עולה כסף** — כל צעד הוא קריאת API עם תמונה (עשרות צעדים לעריכה).
- **בטיחות** — הזזת העכבר לפינה השמאלית-עליונה עוצרת מיד (pyautogui failsafe). גם Ctrl+C.
- הריצי קודם על משימה קטנה ("פתח את CapCut וצור פרויקט חדש") לפני זרימה מלאה.

## התקנה (פעם אחת)
```
cd C:\Users\osher\AAA\nanobanana-mcp\agent
py -3.11 -m venv agentenv
agentenv\Scripts\python.exe -m pip install --upgrade pip
agentenv\Scripts\python.exe -m pip install -r requirements.txt
```
הגדרת מפתח Anthropic (לא מפתח Gemini/OpenAI):
```
setx ANTHROPIC_API_KEY "sk-ant-..."
```
פתחי חלון PowerShell **חדש** אחרי setx כדי שהמשתנה ייטען.

## הרצה
```
agentenv\Scripts\python.exe computer_agent.py --goal "פתח את CapCut, צור פרויקט 1080x1920, ייבא קליפים מ-C:\Users\osher\AAA\ambiance, סדר אותם עם מעברי Dissolve, הוסף כותרת AAA ACADEMY בכסוף, וייצא ל-MP4"
```
טיפים:
- התחילי ממשימה זעירה לבדיקה: `--goal "פתח את CapCut וצלם מה אתה רואה"`.
- `--max-steps 80` להגדלת מספר הצעדים למשימות ארוכות.
- ככל שהמשימה ספציפית ומחולקת לשלבים — הסוכן מדייק יותר.

## כיול נפוץ
- אם הקליקים נופלים לא-מדויק: נסי להגדיל `TARGET_W` ל-1536 בקובץ (יותר דיוק, יותר טוקנים).
- אם המודל לא מזהה אלמנט בעברית: תני לו הנחיה טקסטואלית ("הכפתור בפינה הימנית-עליונה").
- אם Anthropic עדכנו את גרסת כלי ה-computer-use: עדכני `TOOL_TYPE` ו-`BETA_HEADER` בראש `computer_agent.py` לפי התיעוד.
